# ช่วยตั้งราคา

เครื่องมือตั้งราคาเมนู ไฟล์เดียว (`index.html`) ไม่ต้อง build ไม่มีเซิร์ฟเวอร์ ไม่มีฐานข้อมูล

**วิธีใช้**
1. (ครั้งแรก) เปิด "รายการราคาวัตถุดิบ" แล้วก๊อป 2 คอลัมน์จาก Excel (ชื่อ, ราคาต่อกก./ลิตร/ชิ้น) มาวาง กดนำเข้า
2. กรอก "ล็อตนี้ทำได้กี่จาน" และวัตถุดิบที่ใช้ทั้งล็อต (พิมพ์ชื่อ ระบบดึงราคาให้) บวกค่าไฟ ค่าน้ำ ค่าแรง ฯลฯ
3. ได้ต้นทุนต่อจาน → เลือกเป้ากำไร → ดูราคาแนะนำ → กรอกราคาขายจริงเพื่อดูกำไรย้อนกลับ

**สูตร** (ตรงกับฟอร์ม Excel ตัวอย่าง): ต้นทุนวัตถุดิบ = ราคา × ปริมาณ ÷ 1000 (กรัม/มล.) · ต้นทุนต่อจาน = ต้นทุนทั้งล็อต ÷ จำนวนจาน · ราคาแนะนำ = ต้นทุนต่อจาน ÷ (1 − กำไร%)

**ข้อมูล**
- รายการราคาวัตถุดิบเก็บใน localStorage ของเบราว์เซอร์เครื่องนั้นเท่านั้น ไม่ถูกส่งขึ้นเว็บ (เปลี่ยนเครื่อง/เบราว์เซอร์ต้องนำเข้าใหม่)
- ช่วงอ้างอิงกำไรมาจากรายงานต่างประเทศ (Baker Tilly, Johnson & Wales, Owner.com, Supy) ไม่ใช่ข้อมูลร้านไทย
- กำไรคือกำไรขั้นต้นเทียบต้นทุนเมนู ยังไม่หักค่าเช่า ค่าอื่นที่ไม่ได้ใส่
- แก้ช่วงอ้างอิงที่ตัวแปร `CATS` ในส่วน `<script>` ท้ายไฟล์ `index.html`

เปิดใช้: GitHub Pages (Settings → Pages → Deploy from a branch → main / root)
